## FAQ

### Is OmniPatch safe to use on my computer?

OmniPatch is developed with safety in mind and does not contain tool, components, or modules. It modifies application configurations locally without connecting to external servers.

### Which AI applications are currently supported?

OmniPatch supports ChatGPT, Claude, Perplexity, Microsoft Copilot, Cursor, GitHub Copilot, Devin, and JetBrains AI Assistant. Support for new applications is added regularly.

### How often is OmniPatch updated?

Updates are released within 48 hours whenever a supported application receives changes that might affect patching. Major updates follow application version releases.

### Will using OmniPatch violate the terms of service of the AI apps?

OmniPatch operates at the local client level. Users should review and accept the terms of service of each application independently.

### Do I need an internet connection after patching?

An internet connection is required for the AI applications to function normally. OmniPatch itself does not require an ongoing connection after patching.

### Can I revert the changes made by OmniPatch?

Yes, OmniPatch includes a 'Restore Original' function that can revert all modifications, returning applications to their original state.

### What are the system requirements for OmniPatch?

OmniPatch requires Windows 10 or 11 (64-bit), administrator privileges, and .NET Framework 4.8 or higher installed.

### Does OmniPatch collect any personal data?

No, OmniPatch operates entirely offline and does not collect, transmit, or store any personal data or usage statistics.

### Why do I need to run OmniPatch as administrator?

Administrator privileges are required because OmniPatch modifies system and application configuration files that are protected by Windows User Account Control.
